# Plholdergenbot (@Plholdergenbot)

A production-ready Telegram Bot built with Python 3.11+, `aiogram 3.x`, and Pillow. It generates highly customizable placeholder images on demand with auto-scaled dynamic centered text.

## Features
- **Presets & Custom Dimensions:** Support dimensions from 50x50 to 2000x2000.
- **Color Customization:** Quick background/text presets and raw HEX color input.
- **Dynamic Text Scaling:** Text automatically shrinks or expands to perfectly fit boundaries without clipping.
- **Formats:** Exports clean PNG, JPG, and WEBP formats.
- **Quick Command Generation:** Instant `/placeholder 800 600` generation.
- **Memory Optimized:** In-memory stream generation (no temporary files remaining on disk).
